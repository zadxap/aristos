# Свой CSS — документация (modder API v0)

«Свой CSS» находится в **Меню → Стили и кастомизация**. Всё, что ты туда
пишешь, применяется поверх всех стилей приложения: слой вставляется
последним в `<head>`, поэтому перекрывает и стандартную тему, и выбранный
стиль. Сохраняется на устройстве и применяется до первой отрисовки — без
мигания.

## Как это работает

- Это обычный CSS. Синтаксис — стандартный: `селектор { свойство: значение; }`
- Поддерживается всё, что понимает браузер: медиазапросы, `:hover`,
  CSS-переменные, `backdrop-filter` и т.д.
- Стиль применяется **сразу при вводе** и сохраняется на каждой клавише
- Кнопка «Очистить» убирает весь пользовательский слой

## Куда цепляться: стабильные хуки

Приложение построено на CSS-переменных (цвета, радиусы, шрифты) и
`data-slot`-атрибутах компонентов. Это самые надёжные селекторы — они не
зависят от случайных классов.

### CSS-переменные (самый мощный способ)

Задаются на `:root` (для светлой темы) и в `.dark` (для тёмной):

| Переменная                       | Что меняет                                         |
| -------------------------------- | -------------------------------------------------- |
| `--primary`                      | акцентный цвет (кнопки, ссылки, активные элементы) |
| `--primary-foreground`           | текст на акцентных элементах                       |
| `--background`                   | фон страницы                                       |
| `--card`                         | фон карточек (можно с прозрачностью)               |
| `--border`                       | цвет рамок                                         |
| `--muted` / `--muted-foreground` | приглушённые фоны и текст                          |
| `--secondary`, `--accent`        | вторичные поверхности                              |
| `--ring`                         | цвет фокуса при вводе                              |
| `--radius`                       | базовый радиус скруглений (влияет на всё)          |
| `--app-font`                     | шрифт интерфейса                                   |

### data-slot атрибуты компонентов

| Селектор                                                      | Компонент                   |
| ------------------------------------------------------------- | --------------------------- |
| `[data-slot="card"]`                                          | карточки                    |
| `[data-slot="card-title"]` / `[data-slot="card-description"]` | заголовок/описание карточки |
| `[data-slot="button"]`                                        | все кнопки                  |
| `[data-slot="badge"]`                                         | бейджи-чипы                 |
| `[data-slot="progress"]` / `[data-slot="progress-indicator"]` | полосы прогресса            |

### Классы-хуки стилевых пакетов

Выбранный стиль добавляет класс на `<html>`:
`style-monolith`, `style-cobalt`, `style-deck`, `theme-glass`.
Через них можно менять поведение конкретного стиля.

## Примеры

### Перекрасить акцент в зелёный и скруглить сильнее

```css
:root {
  --primary: #10b981;
  --ring: #10b981;
  --radius: 18px;
}
.dark {
  --primary: #34d399;
}
```

### Стекло без размытия на карточках (оставить только в модалках)

В пресете «Стекло» убери блюр карточек — прозрачность останется,
а модалки как размыты (их слой из modal.tsx), так и останутся:

```css
/* ничего добавлять не нужно: в пресете «Стекло» карточки уже без блюра.
   Если хочешь вернуть блюр карточкам: */
.theme-glass [data-slot="card"] {
  -webkit-backdrop-filter: blur(16px);
  backdrop-filter: blur(16px);
}
```

### Своё фоновое свечение (как в стиле «Кобальт»)

```css
.style-cobalt {
  background-image:
    radial-gradient(
      60rem 40rem at 80% -10%,
      rgb(99 102 241 / 0.35),
      transparent 65%
    ),
    radial-gradient(
      40rem 30rem at 0% 100%,
      rgb(14 165 233 / 0.25),
      transparent 60%
    );
  background-attachment: fixed;
}
```

### Тонкая настройка кнопок

```css
/* круглые кнопки-иконки */
[data-slot="button"] {
  border-radius: 12px;
}

/* только основные (синие) кнопки — светящаяся тень */
[data-slot="button"].bg-primary {
  box-shadow: 0 2px 14px rgb(37 99 235 / 0.45);
}
```

### Прятать элемент, который не нужен

```css
/* пример: скрыть подсказку в карточке радара */
[data-slot="card"] .text-muted-foreground {
}
/* так делать не стоит — лучше точечно по тексту или структуре */
```

## Что может сломаться

- Слишком агрессивные селекторы (`* { … }`) тронут всё подряд
- Прозрачный `--background` сделает нечитаемым текст на фоне
- `display: none` на нужных блоках скроет функциональность
- Всегда можно нажать «Очистить» — приложение вернётся к стандартному виду

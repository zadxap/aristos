# Curriculum Builder (Aristos)

Автономное веб-приложение для студенческого дашборда Aristos: визуальный редактор,
который генерирует JSON-конфиги учебной программы в трёх форматах:

| Вкладка | Документ | Имя файла |
| --- | --- | --- |
| **Пән** | Предмет (силлабус): темы по неделям, преподаватель, PDF-ссылки | `<subject_id>.json`, напр. `aleumettanu.json` |
| **Кесте** | Расписание пар на курс/семестр | `schedule.json` |
| **Күнтізбе** | Академический календарь: семестры, рубежки, сессия, каникулы | `acad_calendar.json` |

Приложение полностью автономно: живёт в `tools/curriculum-builder`, имеет свой
`package.json` и ничего не знает про сборку основного репозитория.

## Запуск

```bash
cd tools/curriculum-builder
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build      # tsc (строгая проверка типов) + vite build -> dist/
npm run preview    # локальный просмотр собранной версии
```

## Переменные окружения (необязательно)

Скопируйте `.env.example` в `.env.local` и при желании заполните — тогда панель AI
будет предзаполнена. Значения из env используются **только если** пользователь не
задал свои в панели «AI-ассистент» (пользовательские настройки хранятся в localStorage
и имеют приоритет). Env действует на провайдер «OpenAI-совместимый»; настройки Gemini
живут только в localStorage.

| Переменная | Смысл | По умолчанию |
| --- | --- | --- |
| `VITE_AI_BASE_URL` | Базовый URL OpenAI-совместимого API | `https://api.openai.com/v1` |
| `VITE_AI_API_KEY` | API-ключ (Bearer) | — |
| `VITE_AI_MODEL` | Модель | `gpt-4o-mini` |

## Как пользоваться

### 1. Пән (Subject)
- Заполните скалярные поля (`subject_id` — слаг из `a-z0-9_-`, например `aleumettanu`), преподавателя, описание.
- **Темы**: добавляйте строки, выбирайте тип (`lecture/practice/lab/srsp/srs/mini_project/military/other`), номер недели, текст; стрелками ↑↓ меняйте порядок.
- **PDF-ссылки** — опциональный блок: кнопка «Добавить PDF-ссылки» создаёт список, кнопка ✕ у последней строки убирает его целиком.
- Кнопка **«＋ Сохранить текущий пән»** в панели «Мои пәндеры» кладёт предмет в справочник (localStorage). Этот справочник используется во вкладке «Кесте» для автозаполнения `subject_id` / `subject_name`. Клик по сохранённому предмету открывает его обратно в редакторе.

### 2. Кесте (Schedule)
- Укажите `course` / `semester`, добавляйте строки пар: день, время начала/конца, предмет, тип (lecture/practice/—), аудитория, преподаватель, группа, дата начала действия.
- Если «Мои пәндеры» не пусты — поля `subject_id` и `subject_name` автозаполняются через datalist.
- Кнопка **«↕ Сортировать»** упорядочивает записи по дню недели и времени.

### 3. Күнтізбе (AcadCalendar)
- `course` и `academic_year` (формат `2026-2027`).
- Карточка на каждый семестр: даты начала/конца, `total_weeks`, orientation_week, exam_period, списки рубежных контролей и каникул (название опционально). Семестры можно добавлять и удалять.
- Ниже — общий список практик и `grading_period`.

### 4. Импорт и экспорт
- **Импорт JSON**: выберите существующий файл — он загрузится в активную вкладку (если структура относится к другому типу документа, приложение само переключится на подходящую вкладку).
- **Экспорт**: перед выгрузкой документ проверяется валидатором; список ошибок виден под редактором, а кнопки «Скачать файл» и «Копировать» активируются только когда ошибок нет. JSON форматируется с отступом 2 пробела; имена файлов: `<subject_id>.json` / `schedule.json` / `acad_calendar.json`.

### 5. AI-ассистент

#### Провайдеры
В панели AI-ассистента выбирается провайдер (настройки хранятся отдельно для каждого):

| Провайдер | Запрос | Настройки | Когда использовать |
| --- | --- | --- | --- |
| **OpenAI-совместимый API** (по умолчанию) | `POST {Base URL}/chat/completions`, `Authorization: Bearer`, `temperature 0.2` | Base URL (`https://api.openai.com/v1`), API key, Model (`gpt-4o-mini`); fallback на `VITE_AI_*` env | OpenAI, любые OpenAI-совместимые прокси (omniroute и т.п.) |
| **Google AI Studio — Gemini** (нативный REST, без SDK) | `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key=…`, `temperature 0.2`; ответ из `candidates[0].content.parts[].text` | API key, Model (`gemini-2.5-flash-lite`) — только localStorage | PDF-файлы и картинки (в т.ч. сканы — OCR делает сам), прямой доступ к Google |

Пример настройки под PDF: получите бесплатный ключ на [aistudio.google.com](https://aistudio.google.com) →
провайдер «Google AI Studio — Gemini» → вставьте ключ → модель `gemini-2.5-flash-lite` → прикрепите PDF силлабуса → «Сгенерировать».

**Пресеты моделей**: под полем Model — datalist со списком (поле остаётся свободным вводом).
Gemini: `gemini-2.0-flash`, `gemini-2.0-flash-lite`, `gemini-2.5-flash`, `gemini-2.5-flash-lite` (самые дешёвые по лимитам — flash-lite), `gemini-2.5-pro`, `gemini-3.5-flash-lite`.
OpenAI-совместимый: `gpt-4o-mini`, `gpt-4o`, `gpt-4.1-mini`, `gpt-4.1`, `o4-mini` — модель зависит от твоего прокси (omniroute и т.п.), впиши свою.

#### Файлы (PDF / TXT / картинки)
Кнопка **«📎 Прикрепить файлы»** рядом с textarea исходника: можно выбрать сразу несколько файлов
(`.pdf`, `.txt`, `.png`, `.jpg`, `.jpeg`, `.webp`), они показываются чипами с типом
(PDF/TXT/IMG + имя + размер + удалить). Суммарный лимит — **15 МБ**.

- **Gemini**: PDF и картинки уходят как `inline_data`-части (`application/pdf` / `image/*`, base64), TXT — текстовой частью. Сканы (PDF и фотки страниц) обрабатывает сам Google (OCR) — это основной сценарий для больших силлабусов со списками и таблицами.
- **OpenAI-совместимый**: PDF прикрепляется content-частью `{type:"file", file:{filename, file_data:"data:application/pdf;base64,…"}}`, картинки — `{type:"image_url", image_url:{url:"data:image/…;base64,…"}}`, TXT — текстовой частью. Многие прокси не принимают вложения: если API вернёт 4xx при приложенных файлах, приложение подскажет переключиться на Gemini или вставить текст вручную.
- Текст из textarea и файлы объединяются в один запрос: системный промт со схемами + задача + содержимое файлов. Можно генерировать только из файлов, без текста.

#### Генерация
1. Раскройте панель «AI-ассистент» справа, выберите провайдера и впишите настройки. Ключ никуда не отправляется, кроме выбранного вами API.
2. Вставьте исходный текст и/или прикрепите файлы.
3. Выберите, что генерировать (по умолчанию — активная вкладка), и нажмите **«✦ Сгенерировать»**. Системный промт жёстко описывает все три схемы и требует ответ «чистым» JSON (markdown-обёртка ```json срезается автоматически).
4. Ответ парсится и валидируется: при успехе документ сразу загружается в редактор, при расхождении со схемой — показывается список ошибок и сырой ответ модели (для отладки).

#### Ручной режим: «Скопировать промт»
Кнопка **«Скопировать промт»** копирует полный промт (системная часть со всеми схемами + задача + вставленный исходный текст; файлы в этот текстовый путь не входят). Рабочий цикл без прямого доступа к API:

1. Настройте селект «что генерировать» и вставьте исходный текст.
2. Нажмите «Скопировать промт» (или скопируйте текст из textarea в блоке «Промт целиком»).
3. Вставьте промт в любой ИИ (ChatGPT, Claude, …) и получите JSON.
4. Сохраните ответ в файл и загрузите через **«Импорт JSON»** — или вставьте прямо в textarea и нажмите «Сгенерировать», если ключ всё же настроен.

## Структура проекта

```
tools/curriculum-builder/
├── index.html
├── package.json            # собственный, независимый от корня репозитория
├── tsconfig.json
├── vite.config.ts
├── .env.example
├── README.md
└── src/
    ├── main.tsx            # точка входа
    ├── App.tsx             # вкладки, автосохранение, импорт/экспорт, композиция панелей
    ├── styles.css          # тёмная тема (обычный CSS)
    ├── types.ts            # Subject / Schedule / AcadCalendar — источник истины
    ├── lib/
    │   ├── parse.ts        # структурный парсер JSON (импорт + ответ ИИ), нормализация дат/времени
    │   ├── validate.ts     # контентная валидация перед экспортом (список ошибок)
    │   ├── sanitize.ts     # сборка чистого документа на экспорт (тримминг, опциональные поля)
    │   ├── storage.ts      # localStorage: черновики, «Мои пәндеры», настройки AI (по провайдерам)
    │   ├── defaults.ts     # пустые документы
    │   ├── prompt.ts       # системный промт со всеми схемами + сборка полного промта
    │   ├── ai.ts           # клиенты OpenAI-compat и Google Gemini, env-настройки, извлечение JSON
    │   ├── attachments.ts  # файловые вложения (PDF/картинки→base64, TXT), лимит 15 МБ
    │   └── download.ts     # скачивание файла, копирование в буфер
    └── components/
        ├── SubjectEditor.tsx
        ├── ScheduleEditor.tsx
        ├── CalendarEditor.tsx
        ├── LibraryPanel.tsx    # «Мои пәндеры»
        ├── ImportPanel.tsx
        ├── ExportPanel.tsx
        ├── AiPanel.tsx
        ├── ValidationList.tsx
        └── bits.tsx            # Section / TextField / NumberField / TextAreaField
```

## Хранение данных

- Черновики всех трёх вкладок автосохраняются в localStorage (ключи `aristos-cb:draft:*`); кнопка **«Очистить»** в шапке их удаляет.
- Справочник «Мои пәндеры» — `aristos-cb:library`.
- Настройки AI — `aristos-cb:ai-settings`.

# Aristos Sync — расширение для Chrome/Edge (MV3)

Тянет дедлайны и оценки из `canvas.yu.edu.kz` под твоей **живой сессией** (API-токены в ЮАУ
запрещены админами — расширению они и не нужны: используются session cookie + CSRF из куки)
и заливает их в дашборд Aristos через `postMessage`.

## Установка (2 минуты)

1. Скачай/склонируй папку `extension/`.
2. Chrome или Edge → адресная строка: `chrome://extensions` (или `edge://extensions`).
3. Включи **«Режим разработчика»** (переключатель справа сверху).
4. Нажми **«Загрузить распакованное расширение»** → выбери папку `extension/`.
5. На панели появится иконка Aristos — закрепи её (булавка).

Для друзей: заархивируй папку `extension/` в zip — пусть повторят те же 4 шага.
Позже можно опубликовать в Chrome Web Store ($5 разовый взнос) — тогда установка будет в один клик.

## Настройка (один раз)

1. Кликни по иконке расширения.
2. **Адрес дашборда**: `http://localhost:5173` (dev) или твой прод-URL (например `https://aristos.vercel.app`).
3. Нажми **OK** — Chrome спросит разрешение на доступ к этому адресу (нужно, чтобы расширение
   могло передавать данные в открытую вкладку дашборда). Разреши.
4. Нажми **«Синхронизировать»**. Расширение откроет (или переиспользует) вкладку дашборда
   и передаст туда данные — на странице «Мерзімдер» появится тост об успехе.

## Что синхронизируется

- Курсы + итоговый балл (`current_score`) по каждому — видно в стрипе «Canvas бағалары»
- Все задания/тесты/дискуссии с дедлайнами, статусом сдачи, опозданием и оценкой
- Привязка Canvas-курсов к предметам дашборда — кнопка «Курстарды байланыстыру» на странице «Мерзімдер»
- **Платонус** (кнопки «Платонус · журнал оценок»): находит доступные периоды
  (год × термин) и импортирует журнал — карточки предметов (Ср.тек, РК, Рейтинг,
  Экз, итог-%) + оценки по дням из модалки каждого предмета (лекция/практика/СРСП).
  Синк открывает скрытую вкладку Платонуса и кликает карточки — занимает пару минут,
  прогресс виден в попапе (можно закрыть — синк продолжится в фоне).
  HTML дампа журнала для отладки парсера: кнопка «HTML журнала» (появляется после синка).

## Если push не сработал

Расширение предложит **скачать JSON** — его кидаешь в дашборде: Мәзір → «Деректерді импорттау».

## Приватность

- Все запросы идут напрямую из твоего браузера в canvas.yu.edu.kz и в твой дашборд
- Расширение ничего никуда не отправляет кроме как в указанный тобой адрес дашборда
- Токен календаря/пароли не используются и не хранятся; в расширении хранится только адрес дашборда и время последнего синка

## Файлы

- `manifest.json` — MV3-манифест, хост-пермиссии
- `background.js` — service worker: фетч Canvas (пагинация, CSRF), Platonus-журнал (hidden-таб + клики карточек), push во вкладку дашборда
- `platonus-inpage.js` — функции, исполняемые в вкладке Платонуса (парсер карточек, сборщик оценок по дням); тестируются через jsdom: `tools/test-platonus-parser.mjs`
- `popup.html` / `popup.js` — UI: адрес дашборда, кнопка синка, прогресс-стадии, запасной экспорт JSON
